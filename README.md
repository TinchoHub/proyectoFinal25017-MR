# 🛍️ StarShop — E-Commerce Web Application

Plataforma de comercio electrónico moderna desarrollada como Single Page Application (SPA) utilizando **React 19**, **Vite** y **React Router v7**, con diseño responsivo y despliegue continuo en **Netlify**.

---

## 🚀 Características Principales

- **Catálogo Dinámico & Navegación Fluida:** Enrutamiento desacoplado del lado del cliente mediante `react-router-dom` (v7).
- **Interfaz Responsiva:** Maquetación con **Bootstrap 5** y componentes estilizados con **React-Bootstrap**.
- **Gestión de Notificaciones:** Sistema interactivo de alertas y feedback al usuario mediante `react-toastify`.
- **Optimización SEO:** Control dinámico de cabeceras, títulos y meta-etiquetas por vista utilizando `react-helmet-async`.
- **Configuración Cloud Ready:** Enrutamiento SPA configurado para Netlify con redirecciones automáticas a `/index.html`.

---

## 🛠️ Stack Tecnológico

- **Frontend Core:** [React 19](https://react.dev/) + [React DOM 19](https://react.dev/)
- **Bundler & Build Tool:** [Vite 6](https://vite.dev/)
- **Enrutamiento:** [React Router DOM v7](https://reactrouter.com/)
- **Estilos & UI:** Bootstrap 5.3, React-Bootstrap, React Icons, FontAwesome Free
- **Feedback & Notificaciones:** React Toastify
- **Despliegue:** [Netlify](https://www.netlify.com/)

---

## 📦 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   git clone https://github.com/TinchoHub/proyectofinal25017-mr.git
   cd proyectofinal25017-mr

2. **Instalar dependencias:**
   npm install

3. **Iniciar el entorno de desarrollo:**
   npm run dev

4. **Compilar para producción:**
   npm run build
